# ZYNO - The Fizz Revolution

Welcome to the **ZYNO** landing page repository. This is an effervescent, premium, and undeniably *bakchod* web experience for a functional beverage brand that takes itself just seriously enough to use clinical-grade ingredients, but not seriously enough to be boring.

## 🫧 What is ZYNO?
ZYNO was born when we realized that every "health drink" on the shelf tasted like cardboard mixed with regret, or was so full of sugar you might as well eat a donut. 
We spent months losing our minds over formulations, yelling at suppliers, and drinking more test batches than medically advised. The result? Three cans of effervescent madness that taste unreal and actually do something.

## 🚀 Features
- **Premium Pastel Aesthetic**: Smooth, vibrant colors (`--lavender-soft`, `--peach-soft`, `--mint-soft`) that pop out at you.
- **GSAP Animations**: Buttery smooth scroll sequences, pinned 3D-like reveals, bouncy card entrances (`back.out(1.4)` easing).
- **Unhinged Copywriting**: We speak facts. No boring corporate jargon, just pure, unapologetic fizz.
- **Dynamic Color Changes**: Background sections beautifully transition based on the product flavor you select.
- **Mascots**: Meet the Bubble Friend, the Can Dude, and the Nashedi Icecube (in the footer). 

## 🛠️ Tech Stack
- **HTML5**: Semantic and clean.
- **CSS3**: Vanilla CSS with custom properties, smooth transitions, blend modes (`mix-blend-mode: multiply`), and custom animations.
- **JavaScript (Vanilla + GSAP)**: ScrollTrigger for pinned animations, custom scroll sequences, and dynamic background transitions.
- **Three.js** (Optional/Extendable): Ready for floating 3D can integrations.

## 🏃‍♂️ How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/Aryan-Protein-Vala/Zyno.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Zyno
   ```
3. Open `index.html` in your browser, or spin up a quick local server (recommended for GSAP/assets):
   ```bash
   npx serve .
   ```
4. Experience the fizz.
